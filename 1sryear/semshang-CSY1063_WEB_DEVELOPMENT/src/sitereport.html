Introduction

This project is a personal portfolio website developed to showcase my identity, skills, and interest in web and software development. the website serves as a digital profile that introduces me as a bachelor level student and highlights my enthusiasm for modern ber technologies and clean user interface design. the site is built using standard front-end technologies and follows a simple, visually appealing layout

Objective

The main objective of this website are:
  • To create a personal online portfolio.
  • To practise and apply html and css concepts.
  • To learn how to design a website using html and css.
  • To learn how to ensure responsiveness across desktop and movbile devices.

    • Technologies used

    The following technologies were used in the development of this website:
  • HTML5: for structuring the webpage content.
  • CSS3: for styling, layout designs, animations and responsiveness.
  • Media queries: for responsive design for both mobile and desktop.
  • VS-code: for writing and managing languages

    Site-explanation

    Home Page (index.html)

    The home page is the main page of the website. it includes a navigation bar with a logo and links to all other pages. the main section introduces the user with a welcome message, personal details. a decorative background element which is used to enhance the visual appearance, and a footer which is included at the bottom.

    The project page (project.html)

    The project page displays a placeholer project card arranged using CSS Grid. each card contains a project title and a image placeholder. these projects are temporary and are intended to be updated in future modules. this page helps and shows basic grid layout for content organization

    The contact page (contact.html)

    The contact page provides a simple interface with input fields for name, phone-number and email. the layout uses flex box and grid to separate the contact text. this page is designed to allow users to reach out for collaboration or question. as i have not put the contact section because this is a prototype version of first project.

    The demo video page (demo video.html)

    The demo video page contains a demo video element along with heading and youtube link. the page layout places text and video side by side on larger screens and attempts to stack them on smaller screens. this page demonstrates the use of html video elements and media content.

    Conclusion

    The personal portfolio website successfully meets its objectives by presenting a clean, structured website, however the responsive page for every html file doesn't work i dont know what could be the reason as i have checked but in further projects i will make sure every thing works out as the objectives. well the page demonstrates basic front-end development skills and provides a strong foundation for future enhancements. the project has improvd my understanding of HTML structure, CSS styling, how ever i have to work on the responsive design more and understand it.
